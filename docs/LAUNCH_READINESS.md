# عقاري برو — بوابة الجاهزية للإطلاق التجاري

الإصدار الأول مخصص **للمالك الفردي الذي يدير عقاراته بنفسه**. إصدار مكاتب إدارة الأملاك خارج نطاق V1.

## الوضع الحالي
- واجهة GitHub Pages: نسخة تجريبية، تحفظ بيانات المستخدم في المتصفح.
- Backend: أساس Laravel API في فرع التطوير `feature/production-foundation`.
- CI: فحص تركيب PHP واختبارات عزل الملاك والعقود والأقساط والمرفقات.
- GitHub Pages **لا يشغّل Laravel/PHP** ولا يوفر قاعدة بيانات خادمية.

## معيار قبول كل جزء
| المجال | وضع التنفيذ | المطلوب قبل الإطلاق |
|---|---|---|
| قاعدة بيانات ملاك وعقارات | أساس Laravel منشأ | نشر MySQL/PostgreSQL مع migrations وخطة استعادة |
| عزل بيانات المستخدمين | اختبارات أولية | مراجعة أمنية كاملة واختبارات IDOR لكل endpoint |
| مصادقة المستخدم | تسجيل دخول برموز Sanctum | إدارة التسجيل الآمن، إعادة كلمة المرور، الجلسات، MFA للحسابات الحساسة |
| العقارات والوحدات | API إنشاء وقراءة | CRUD مكتمل وحذف منطقي وسجل تغييرات |
| المستأجرون والعقود | API أولي | ملفات المستأجر والعقد، حالات إنهاء وتجديد، مرفقات وتواريخ دقيقة |
| الاستحقاقات والتحصيل | جدول أقساط وقيود مبلغ | توزيع الدفعات على الأقساط، التسويات، المرتجعات، تقارير الديون |
| المصروفات والصيانة | API أولي | إدارة طلب كاملة، مورّدين، موافقات وفواتير |
| المرفقات | تخزين خاص وفحص ملكية | فحص البرمجيات الخبيثة، حدود المستخدم، تشفير، تخزين S3 خاص، سياسة احتفاظ |
| التقارير ولوحة التحكم | API إحصائي أولي | تقارير مؤرخة قابلة للتصدير وتطابق إجمالي الحسابات |
| التدقيق والمراقبة | غير مكتمل | سجل عمليات غير قابل للتعديل وتنبيهات وأرشفة |
| النسخ الاحتياطي | غير مكتمل | نسخ مؤتمت واختبار استعادة دوري |
| تكامل إيجار | محاكاة فقط | تكامل رسمي معتمد بعد توفر الوصول والترخيص |
| واجهة الإنتاج | غير مربوطة | استبدال localStorage بـ API مع تسجيل الدخول والمعالجة الأمنية |
| الإطلاق | غير مكتمل | نطاق آمن، HTTPS، إدارة الأسرار، حماية وWAF، مراقبة، اختبارات قبول |

## متطلبات البيئة
1. خادم PHP متوافق وآمن، MySQL/PostgreSQL، قاعدة بيانات غير متاحة للعامة.
2. تخزين مرفقات خاص لا يعرض المستندات عبر روابط عامة.
3. HTTPS وDomain رسمي وإدارة أسرار مستقلة عن المستودع.
4. إدارة حسابات الملاك، حماية استعادة كلمات المرور، ومراجعة الخصوصية.
5. تشغيل migrations وخطة Rollback وخطة نسخ احتياطي واستعادة مجرّبة.
6. تشغيل الاختبارات و`composer audit` وفحص أمن التطبيقات قبل النشر.
7. مراقبة الخادم وحالات فشل الخدمات وإشعارات الإنذارات.
8. تدقيق قانوني وخصوصية عند معالجة بيانات مستأجرين وصكوك وعقود.

## سياسة الإطلاق
- لا تُستخدم النسخة الحالية للبيانات العقارية الحقيقية.
- لا يُعلن المنتج جاهزًا للإطلاق إلا بعد إتمام القائمة السابقة واختبار بيئة staging مستقلة.
- لا يُدمج الفرع إلى `main` إلا بعد مراجعة الشيفرة واكتمال اختبارات القبول.
- لا تُضاف ميزات إدارة مكاتب العقارات إلى V1 حتى يكتمل مسار المالك الفردي.

## دفعة التطوير الحالية — 6 نوفمبر 2026

أنجز على فرع الإنتاج:
- جدول `payment_allocations` يربط كل سند قبض بالأقساط التي سددها بشكل ذري ضمن معاملة قاعدة البيانات.
- توزيع تحصيل الإيجار على الأقساط الأقدم أولًا، مع منع التحصيل الزائد والتقريب غير الدقيق.
- واجهة الاستحقاقات أصبحت تعرض المدفوع والمتبقي والتأخر، واختبارات الدفعات الجزئية والصلاحيات.
- إضافة تعديل العقارات والوحدات والمستأجرين من واجهة المالك الإنتاجية.
- سجل تدقيق للإنشاء والتعديل والحذف على الكيانات المرتبطة؛ يسجل أسماء الحقول المعدلة بدل نسخ بيانات حساسة.
- تقارير التدفق النقدي حسب نطاق التاريخ، وعرض المقبوضات والمصروفات وصافي التدفق لكل عقار.
- تغطية اختبارات للعزل بين الملاك، وتقارير التدفق النقدي، وأحداث التدقيق.

### لا يزال مطلوبًا قبل قبول الإصدار
- تخصيص دفعة يدويًا لقسط محدد، وإلغاء/عكس سندات القبض مع سجل تدقيق وموافقات.
- دورة حياة العقد (التفعيل، التجديد، الإنهاء، إعادة التأمين).
- اكتمال صفحات السجلات والأرشفة والموردين والصيانة والفواتير.
- اختبار أداء تحميل آلاف الوحدات ومئات الآلاف من العمليات.
- النسخ الاحتياطية والاستعادة، إدارة الأسرار، MFA/استعادة الحساب، ومراجعة أمنية.
- ربط استضافة فعلية بخادم Laravel وHTTPS ونقل البيانات من النسخة التجريبية.
- لا توجد استضافة Production أو بيانات فعلية أو تكامل إيجار رسمي في الوقت الحالي.

## الدفعة التالية: العقود والموردون وأمان الحساب وإلغاء السندات

- دورة العقد: تفعيل المسودة، إلغاء المسودة غير المحصّلة، وإكمال العقد بعد الانتهاء وسداد الأقساط.
- إدارة الموردين المرتبطين بمالك واحد وإمكانية إسناد بلاغ الصيانة لمورد تابع للمالك، مع اختبارات منع الإسناد عبر المحافظ.
- تغيير كلمة المرور مع التحقق من القديمة وإلغاء جميع الرموز النشطة، ودعم واجهته داخل بوابة المالك.
- إلغاء أثر سند قبض مع إلزام سبب الإلغاء وحفظ السند والتوزيعات ضمن سجل تاريخي؛ تُستبعد السندات الملغاة من الأرصدة والتقارير والتحصيل.
- عرض أزرار تغيير حالة العقود وإلغاء السندات مباشرة في بوابة المالك.
- دليل عملي للنشر الآمن ومراقبة التشغيل والنسخ الاحتياطية: `docs/DEPLOYMENT_RUNBOOK.md`.
- اجتياز **40 اختبارًا و144 تأكيدًا** في آخر تشغيل للوظائف قبل تحديث الدليل.

**لم يتم إطلاق الإصدار الإنتاجي**؛ ما زالت استضافة Laravel والنسخ الاحتياطية والأمن واختبارات القبول الشاملة ومراجعة التسويات والتجديدات متطلبات مانعة للإطلاق.
