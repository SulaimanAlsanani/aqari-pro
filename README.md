# عقاري برو | Aqari Pro

واجهة عربية تجريبية لإدارة الأملاك العقارية، تشمل الملاك والعقارات والوحدات والمستأجرين والعقود والأقساط والتحصيل والمصروفات والصيانة والتقارير، ومركز محاكاة لتكامل منصة إيجار.

## تشغيل الموقع عبر GitHub Pages
1. افتح Settings → Pages.
2. في Build and deployment اختر Source: **GitHub Actions**.
3. افتح Actions وتحقق من نجاح **Deploy Aqari Pro to GitHub Pages**.
4. سيظهر الموقع عادة على: https://sulaimanalsanani.github.io/aqari-pro/

## حدود النسخة الحالية
- هذه نسخة **تجريبية مبسطة** للنشر الثابت؛ لا تمثل جميع ميزات النسخة التفصيلية الأصلية.
- البيانات تحفظ محليًا في متصفح المستخدم فقط، ولا توجد مزامنة مركزية.
- لا توجد مصادقة أو إدارة صلاحيات أو قاعدة بيانات.
- جميع إجراءات منصة إيجار **محاكاة محلية** وليست إرسالًا أو توثيقًا رسميًا.
- لا تستخدم بيانات مستأجرين أو ملاك حقيقية أو مفاتيح API في هذا المستودع العام.
- الاستخدام الإنتاجي يتطلب Backend وDB وخدمات أمنية وتكامل إيجار معتمدًا.

## الملفات
- `index.html`: الواجهة العربية
- `app.js`: وظائف النموذج التجريبي
- `.github/workflows/deploy.yml`: نشر GitHub Pages تلقائيًا
